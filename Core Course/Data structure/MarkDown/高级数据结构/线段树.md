## 统计矩形面积

[蓝桥题目](https://www.lanqiao.cn/problems/105/learning/?page=1&first_category_id=1&second_category_id=3&difficulty=20&difficulty_level_gte=6&difficulty_level_lte=10)

此题目的**关键难点**：如何巧妙**避开矩形的重叠部分多次计算**

### 第一维度：暴力染色
- 我们不妨**直接把所有的矩形都涂上色**，这样矩形的重叠与否就**被统一处理**了，然后直接遍历整个二维表格，统计所有涂色的方格
- **时间复杂度：** $O(N \times MAXN^2)$
- **空间复杂度：** $O(MAXN^2)$
- 显然该算法适合在**MAXN**较小的情况下，否则时空爆炸

### 第二维度：单轴离散化+扫描线

- 根据暴力染色的痛点，如果每个矩形的长宽都是MAX，时间复杂度非常高，我们的优化点可以放在**让多个矩形一起涂色**

- 又考虑到，我们暴力算法实际上是**把整个图割成宽度为1的小条**，然后**统计这个小条上的涂色的格子数**

- 我们如果想要统一涂色，并且一条一条的统计，我们就要对每个条记录它的统计情况。但是**矩形的边是离散的**，如果对每个条都记录的话，我们还要从左边界遍历到右边界。

- 我们不如**只存储矩形的左右边界**，这样就形成一条一条线(扫描线)，在左边界时，把矩形的上下边界内的y进行涂色，右边界时取消涂色，这里**本质上是`+1` `-1`的差分思想**，不能直接清零，而是**让覆盖次数减`1`**

- 我们必须对这些线进行排序才能达到**从左到右遍历**的目的

- **时间复杂度：**$O(n*MAXN)$
- **空间复杂度：**$O(MAXN+n)$

```C++
#include <bits/stdc++.h>
using namespace std;
const int MAXN=10005;
struct Edge{
    int x,y1,y2;
    int type; //1表示左边界，-1表示右边界 
};
int main()
{
    // 请在此输入您的代码
    int n;
    cin>>n;
    vector<Edge>edges;
    for(int i=0;i<n;i++){
    	int x1,y1,x2,y2;
		cin>>x1>>y1>>x2>>y2;
		int X1=min(x1,x2),Y1=min(y1,y2); 
		int X2=max(x1,x2),Y2=max(y1,y2);  
		
		edges.push_back({X1,Y1,Y2,1});
		edges.push_back({X2,Y1,Y2,-1});
	} 
	
	sort(edges.begin(),edges.end(),[](auto &u,auto &v){
		return u.x<v.x;
	}) ;
	
	int last_x=edges[0].x;
	vector<int>pointY(MAXN);
	int res=0;
	
	for(int i=0;i<edges.size();i++){
		int dx=edges[i].x-last_x;
		if(dx>0){
			int count=0;
			for(int k=0;k<MAXN;k++) {
				if(pointY[k]>0) count++;
			}
			res+=count*dx;
			last_x=edges[i].x; 
		} 
		for(int j=edges[i].y1;j<edges[i].y2;j++){
			pointY[j]+=edges[i].type; 
		}
	}
	
	cout<<res;
    return 0;
}
```

### 第三维度：双轴离散化

- 考虑到如果`y`的范围比较大，但是实际的**点很分散**，我们还用连续来处理浪费了很多时间和空间
- 既然`x`坐标可以离散，`y`坐标也可以，我们把**Y坐标离散化并去重**，这样我没不再是一个一个染色，而是**Y[i]-Y[i-1]整个区间染色**
- 这时我们记录的不再是每个格子的染色情况而是**每个区间的染色情况**

**离散化的模板:**
``` C++
//排序去重
sort(arr.begin(),arr.end());
arr.erase(unique(arr.begin(),arr.end()),arr.end());
//查找位置
int id =lower_bound(arr.begin(),arr.end(),x)-arr.beign();
```

- 时间复杂度：$O(n^2)$
- 空间复杂度: $O(n)$

```C++

#include <bits/stdc++.h>
using namespace std;
const int MAXN=10005;
struct Edge{
    int x,y1,y2;
    int type; //1表示左边界，-1表示右边界 
};
int main()
{
    // 请在此输入您的代码
    int n;
    cin>>n;
    vector<Edge>edges;
    vector<int>Y; 
    for(int i=0;i<n;i++){
    	int x1,y1,x2,y2;
		cin>>x1>>y1>>x2>>y2;
		int X1=min(x1,x2),Y1=min(y1,y2); 
		int X2=max(x1,x2),Y2=max(y1,y2);  
		
		Y.push_back(y1);
		Y.push_back(y2);
		
		edges.push_back({X1,Y1,Y2,1});
		edges.push_back({X2,Y1,Y2,-1});
	} 
	
	sort(edges.begin(),edges.end(),[](auto &u,auto &v){
		return u.x<v.x;
	}) ;
	
	//排序去重 
	sort(Y.begin(),Y.end());
	Y.erase(unique(Y.begin(),Y.end()),Y.end()); 
	
	int last_x=edges[0].x;
	vector<int>pointY(Y.size()-1);
	int res=0;
	
	for(int i=0;i<edges.size();i++){
		int dx=edges[i].x-last_x;
		if(dx>0){
			int count=0;
			for(int k=0;k<pointY.size();k++) {
				if(pointY[k]>0) count+=Y[k+1]-Y[k];
			}
			res+=count*dx;
			last_x=edges[i].x; 
		} 
		int start_id=lower_bound(Y.begin(),Y.end(),edges[i].y1)-Y.begin();
		int end_id=lower_bound(Y.begin(),Y.end(),edges[i].y2)-Y.begin();
		for(int j=start_id;j<end_id;j++){
			pointY[j]+=edges[i].type; 
		}
	}
	
	cout<<res;
    return 0;
}
```
