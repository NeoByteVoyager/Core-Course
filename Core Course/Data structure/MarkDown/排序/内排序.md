
# 八大排序
**内排序**：数据存储和位置的均在内存中进行

--- 
## 一. 插入排序

### 思想
- 将排序集合分为已有序和无序两个集合
- 每次从无序集合中选择一个元素，将其插在有序集合的正确位置

### 代码实现

``` C++
void insertSort(int a[], int l, int r)
{
    for (int i = l + 1; i <= r; i++)
    {
        // 选择第一个无序的元素在有序序列的位置
        int t = a[i]; // 保存当前元素
        int j;
        for (j = i; j >= l + 1; j--)
        {
            if (a[j - 1] > t) // 保证j左边的元素都要小于等于t，可以保持稳定性
                a[j] = a[j - 1];
            else
                break;
        }
        a[j] = t;
    }
}
```
### 优化

可以**通过二分（折半查找）实现$O(log(n))$查找正确插入位置**，但是它**不会改变移动元素的时间复杂度**

## 二.希尔排序

本质是**对选择排序的优化**

### 思想
- 先将整个序列按照一定的步长**分成若干个子序列**,并对每个子序列进行插入排序
- 然后**逐渐缩小步长**，重复上述操作，直到步长为1

### 代码

``` C++
//增量序列
const int dn = 3;
int d[] = {5, 3, 1};
//插入排序
void insertSort(int a[], int l, int r, int d)
{
    //插入排序的1全部变成d
    for (int i = l + d; i <= r; i++) //这里每次走一步
    {
        // 选择第一个无序的元素在有序序列的位置
        int t = a[i]; // 保存当前元素
        int j;
        for (j = i; j >= l + d; j -= d) //这里每次走d步
        {
            if (a[j - d] > t) 
                a[j] = a[j - d];
            else
                break;
        }
        a[j] = t;
    }
}
void shellSort(int a[], int l, int r)
{
    for (int i = 0; i < dn; i++)
    {
        insertSort(a, l, r, d[i]);
    }
}
```

> [!注意]
> 希尔排序的时间复杂度依赖于增量序列，但一般认为它的时间复杂度优于插入排序

## 三.选择排序

### 思想
- 将集合划分为**有序和无序**两个集合
- 每次从无序集合中选取**最小的元素放到有序元素的最后面**

### 代码

``` C++
const int n = 10;
int a[] = {2, 6, 3, 8, 3, 5, 7, 6, 2, 5};
void selectSort(int a[], int l, int r)
{
    for (int i = l; i < r; i++)
    {
        //选取此轮的最小值
        int min_idx = i;
        for (int j = i + 1; j <= r; j++)
        {
            if (a[j] < a[min_idx])
                min_idx = j;
        }
        if (min_idx != i)
            swap(a[i], a[min_idx]);
    }
}

```
## 四.堆排序

### 思想
- 实际上是**对选择排序的一个优化**，选择排序每次选择最小元素需要$O(n)$时间
- 如果**将待排序的序列组成优先级队列**，可以优化每次取最小或取最大
### 代码
```C++
class HeapSort
{
private:
    vector<int> data;
    int n;

public:
    HeapSort(const vector<int> &a)
    {
        // bug1：下标问题
        n = a.size();
        data.resize(n + 1);
        for (int i = 1; i <= n; i++)
            data[i] = a[i - 1];
        build();
        // sort();
    }
    void build()
    {
        for (int i = n / 2; i >= 1; i--)
        {
            shiftDown(i);
        }
    }
    void shiftDown(int idx)
    {
        int t = data[idx];
        int i = idx;
        while (true)
        {
            int child = 2 * i;
            if (child > n)
                break;
            if (child + 1 <= n && data[child + 1] > data[child])
                child = child + 1;
            if (data[child] <= t)
                break;
            data[i] = data[child];
            i = child;
        }
        data[i] = t; // 最后赋值
    }
    void shiftUp(int idx)
    {
        int t = data[idx];
        int i = idx;
        while (i >= 1 && t > data[i / 2])
        {
            data[i] = data[i / 2];
            i = i / 2; // bug2:死循环
        }
        data[i] = t;
    }
    void sort()
    {
        int loop = n;
        while (loop > 1)
        {
            swap(data[1], data[n]); // bug3:错误的交换了全局a
            n--;
            shiftDown(1);
            loop--; // bug：死循环
        }
        cout << "排序完成后的数据:\n";
        for (int i = 1; i < data.size(); i++)
        {
            int v = data[i];
            cout << v << " ";
        }
    }
};
```
