## 埃氏筛
### 思路
#### 初始定义
给定一个正整数集合$S=\{2,3..\}$,假定每个数字都为质数
#### 合数一定标记
- 根据**算术基本定理**，每个合数都可以用**唯一分解**为若干质数相乘
- 考虑一个合数$C$,分解的最小质数为$p$,故$C=K \times p$，$K>1$
- 算法从小到达遍历质数，当遍历到$p$时，算法会将$p$所有大于1的倍数都标记为合数，$C$会被标记为合数
#### 质数一定不会标记
- 假设一个质数$P \in S$，被标记为合数
- 根据算法逻辑，一个数字被标记为合数，只有当它是**某个较小的质数的倍数**
- 由此可知，存在一个质数$p < P$和一个大于1的$k$，$P=p \times k$
- 这就意味着$P$不是质数，矛盾


### 代码：
```
void sliver(){
	// 初始化都为质数 
	for(int i=2;i<=maxn;i++) is_prime[i]=true;
	// 开始筛选
	for(int i=2;i*i<=maxn;i++){
		if(is_prime[i]){
			for(int j=i*i;j<=maxn;j+=i) is_prime[j]=false;
		}
	} 
}
```

- **优化点：** 内层循环要从$p^2$开始
