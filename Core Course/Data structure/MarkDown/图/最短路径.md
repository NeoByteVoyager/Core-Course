## 单源最短路径：Dijkstra
### 算法思想
1. 把整个顶点**集合划分**为已知最短路径集合$U$和未知最短路径的集合$V-U$，初始时已知最短路径集合只有源点(最短路径为0)
2. 每次选择从$V-U$中选择一个顶点$u$，并加入集合$U$中。从源只经过$U$到达$v$，这条路径即为到达$u$的最短路径
3. 修改从$u$出发到集合$V-U$的任意一个顶点的最短路径长度，如果$ dist[u]+M[u][w] < dist[w] $，则更新dist[w]
4. 重复2，3，直到所有顶点都找到了最短路径
### 代码
``` C++
class Solution {
public:
    int networkDelayTime(vector<vector<int>>& times, int n, int k) {
        // times[i] = (ui, vi, wi)，其中 ui 是源节点，vi 是目标节点， wi
        // 是时间。 现在，从某个节点 K 发出一个信号，求最短最长时间

        // 先建立邻接表
        vector<vector<pair<int, int>>> edges(n + 1);
        for (auto& t : times) {
            int u = t[0], v = t[1], w = t[2];
            edges[u].push_back({v, w});
        }
        vector<int> dist(n + 1, INT_MAX);
        priority_queue<pair<int, int>, vector<pair<int, int>>, greater<>>
            pq;          // 这里是greater小根堆
        pq.push({0, k}); // 第一个关键字是权值
        dist[k] = 0;
        // 这里是优先队列不为空
        while (!pq.empty()) {
            auto p = pq.top();
            pq.pop();
            int wi = p.first, ui = p.second;
            if (wi > dist[ui])
                continue;
            for (auto p : edges[ui]) {
                int v = p.first, dw = p.second;
                int w = dw + wi;
                if (w < dist[v]) {
                    dist[v] = w;
                    pq.push({w, v});
                }
            }
        }
        int m = 0;
        for (int i = 1; i <= n; i++)
            m = max(m, dist[i]);
        return m == INT_MAX ? -1 : m;
    }
};
```
### 时间复杂度
每次弹出一个顶点时间$O(log (V))$，总共弹出O(V)个
进行松弛操作时要遍历每条边$O(E)$，最坏下每次都加入堆中，时间$O(Elog(V))$

总时间：$O((E+V)log(V))$

## 带负边权的单源最短路径:Bellman-Ford
### 思想
假设图中共有`n`个顶点
- 由于我们知道，图中任意两点的最短路径**最多经过n-1条边**(如果图中没有负环)
- 所以把起点最短路径初始化为0，其余顶点初始化为无穷大
- 外层循环遍历`n-1`次，代表从一个顶点到另一个顶点最多经历`n-1`条边，内层循环遍历图中每一条边，并用该边进行松弛操作
- 最后判断有无负环：在进行一次松弛操作，如果任意顶点的最短路径减小，则存在负环 

### 代码
```C++
#include <vector>
#include <iostream>

using namespace std;

// 定义边的结构体
struct Edge {
    int u, v, w;
};

bool bellmanFord(int n, int src, vector<Edge>& edges, vector<int>& dist) {
    // 1. 初始化（对应你的第 2 点）
    const int INF = 1e9; // 用 1e9 防止相加时溢出
    dist.assign(n + 1, INF);
    dist[src] = 0;

    // 2. 外层循环 n-1 次，内层遍历所有边（对应你的第 3 点）
    for (int i = 1; i <= n - 1; i++) {
        for (auto& edge : edges) {
            if (dist[edge.u] != INF && dist[edge.u] + edge.w < dist[edge.v]) {
                dist[edge.v] = dist[edge.u] + edge.w; // 松弛操作
            }
        }
    }

    // 3. 检查有无负环：再进行第 n 次松弛（对应你的第 4 点）
    for (auto& edge : edges) {
        if (dist[edge.u] != INF && dist[edge.u] + edge.w < dist[edge.v]) {
            return false; // 任意顶点的最短路径还能减小，说明存在负环！
        }
    }

    return true; // 不存在负环，求解成功
}
```
### 时间复杂度
$O(n*E)$

## 所有顶点对的最短路径：Floyd-Warshall算法
### 思想(中转)
`i`到`j`的最短路径，一定是`i`到`j`直达，或者中间经过某些顶点。如果不是直达，我们可以对问题的拆分:$i\rightarrow j$拆分为$i\rightarrow k$+$k\rightarrow j$。也就是说我们只需求解这两个的最短路径即可。
于是我们思考如何先算出$i \rightarrow k$和$k\rightarrow j$的最短路径
这就要求我们思考计算的顺序来复用之前的状态。
**破局点**：
我们**逐步开放中转节点k**，并计算节点对经过`1~k`节点的最短路。
`i`到`j`的路径中间节点一定有一个最大的`m`，当我们开放这个`m`时，$i\rightarrow m$和$m \rightarrow j$已经知道，即可求得：$i\rightarrow j$最短路
**状态转移方程：**
$$dp[k][i][j] = \min(dp[k-1][i][j], \; dp[k-1][i][k] + dp[k-1][k][j])$$

### 代码
```c++
class Solution {
public:
    int findTheCity(int n, vector<vector<int>>& edges, int distanceThreshold) {
        vector<vector<int>> dist(n, vector<int>(n, INT_MAX));
        for (int i = 0; i < n; i++)
            dist[i][i] = 0;
        for (auto& e : edges) {
            int u = e[0], v = e[1], w = e[2];
            dist[u][v] = dist[v][u] = w;
        }
        // 先求解两个城市间的最短路径
        for (int k = 0; k < n; k++) { // 中间只经过顶点0~k
            for (int i = 0; i < n; i++) {
                for (int j = 0; j < n; j++) {
                    if (dist[i][k] != INT_MAX && dist[k][j] != INT_MAX) {
                        dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j]);
                    }
                }
            }
        }
        int ans = -1, m = n;
        for (int i = 0; i < n; i++) {
            int count = 0;
            for (int j = 0; j < n; j++) {
                if (dist[i][j] <= distanceThreshold)
                    count++;
            }
            if (count <= m) {
                m = count;
                ans = i;
            }
        }
        return ans;
    }
};
```
