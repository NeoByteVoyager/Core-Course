## 1.二叉树右视图

[题目](https://leetcode.cn/problems/binary-tree-right-side-view/description/)

### 题目描述
- 给定二叉树根节点`root`，想象自己**站在二叉树的右侧**，按照自顶部到底部的顺序，返回从右侧能看到的节点的值

### 思路
- 问题可以转化为求解二叉树**每一层的最右侧的值**自顶向下的序列

#### 方法一：递归(自顶向下)
- 可以采用**先右后左**的遍历方式，保证到达每一层时总是先到达最右节点
- 同时**记录当前的`level`**，保证只在结果中记录每一层最右边节点(如果`ans`的`size`等于当前层数，说明该层最右侧已经记录)

#### 方法二：层序遍历

- 层序遍历时只保存每一层最右侧节点的值

## 2.从叶节点开始的最小字符串

[题目](https://leetcode.cn/problems/smallest-string-starting-from-leaf/description/)

### 题目描述
- 给定一颗根节点为`root`的二叉树，树中每个节点都是`[0,25]`范围内的的值，分别代表字母`a`到`z`
- 返回**按字典序最小的字符串**，该字符串从这棵树的叶节点出发到根节点结束

### 思路
>-  容易想到可以先求左右子树的最小字符串，然后加上根节点字符，比较大小，更新最小
>- 但是它**不满足最优子结构**：如果一个字符串时`abab`,另一个是`ab`,我们会选择`ab`,但是如果下一个根节点是`e`,会发现选择`abab`更优

- 正确的思路是使用**自顶向下**遍历,记录当前字符串，每次字符串在前面加上根节点字符
    - 遇到空节点，说明不会到达叶子节点，直接返回
    - 遇到叶子节点，更新`ans`
        - `ans`为初始值
        - 当前字符串小于`ans`
    - 否则，接着遍历左右子树
