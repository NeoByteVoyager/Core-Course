## KMP算法复现

---

### 💡思维洞察：最长前后缀

#### 一.把失败作为有效信息

在**朴素的模式匹配**中，我们遇到不相等的字符时，需要**主串指针回溯**到起始指针，每次回溯都让**上一轮的比较**功亏一篑


为了不让上一轮的比较不浪费，我们要**利用这部分信息**
失败意味着什么？意味着**子串的`0`到`j-1`个字符已经和主串`i`以及前面的j个字符相匹配**

---


#### 二.如何移动指针？

我们既然**不想让主串指针回溯**，为了进行**下一轮比较**，我们要让**子串指针**向前回退（不可能向后移动）

移动到何处呢?
我们不妨假设子串指针移动到`k`$(k<j)$，为了保证匹配能继续主串指针`i`进行，**子串的前`k`个字符要和主串的`i`前面的k个字符匹配**

于是我们得到：
1. $s[i-k,...,i-1]$ 和$t[0, ...,k-1]$相匹配
2. 同时我们由之前的匹配信息知道 $s[i-j,...,i-1]$ 是和 $t[0,...,j-1]$匹配的$(k<j)$

**$t[0,...,k-1]$不就是$t[0,...,j-1]$的前缀**吗，$s[i-k,...,i-1]$不就是与模式串匹配的那部分串的后缀吗，也就是**子串$t[0,...,j-1]$的后缀**

由`1.`可知`s[0,...,j-1]`这个串的**前后缀相同**

至此，我们得到，子串和主串的比较转换为**子串前后缀的比较**，也就是：为了不让**主串的指针回溯**，子串滑动后的位置为`k`,必须满足**长度为`k`的前缀等于后缀**

---

#### 三.为什么移动到最长?

如果移动的不是最长，而是`m` ($m<k$),如果移动到`k`能匹配成功，我们将错过这个解，也就是`k`越大，我们**越不容易错过解**

我们还要证明**移动到最大不会错过解**:
假设有一个解需要移动到`n`($n>k$),那么**子串的长度为`n`的前缀必须和长度为`n`的后缀匹配**，也就是前后缀相同的串长度大于`k`，这**与`k`是最长相矛盾**


---

#### 四.我们该如何快速计算$t[0,...,i]$最长相等前后缀长度

我们为了快得到对于每个`i`，**$t[0,...,i-1]$内前后缀相等的最长前缀的下一个位置**，需要维护一个`next`数组来保存这个值

**暴力求解**：
计算`next`的最朴素想法是**暴力**，对于每个`i`，**枚举长度**，对于**每个长度检查可行性**，复杂度：$O(m^3)$，不可行，需要优化

**动态规划优化**：
**优化的方向**肯定是**历史信息的复用**。暴力求解把**每个next[i]求解都看成了独立的问题**，实际上`next[i]`和`next[i-1]`之间存在着关系

假设我们**已经知道$t[0,...,i-1]$的最长相等前后缀**长度为`j`(即`next[i-1]=j`)
这就意味着$t[0,...,i-1]$的前`j`个字符与后`j`个字符相同
那么在求解$t[0,...,i]$的最长相等前后缀时，自然想到：**这两段相等的前后缀，能不能各自增加一位**

这就分成了两种情况：
**1.字符相等**
如果`t[i]==t[j]`这**两段顺利延长**，`next[i]=j+1`
**2.字符不相等**
我们需要重新开始吗？从头开始找**时间复杂度依旧很高**

我们还需要**借用历史信息**：
假设我们有一个字符串，它的**最长前后缀长度**为`3`,分别是前缀`A B A`后缀`A B A`
现在我们往后多看一个字符发现匹配不上了，我们**退而求其次**，找到其次长相等前后缀

**最巧秒的事情：**
这个次长相等前后缀，**前缀部分一定是`A B A`的前缀，后缀部分一定是`A B A`后缀**
这不就**等价于找`A B A`的最长前后缀**

**而`A B A`的最长相等前后缀就保存在`next`数组里**，直接查表即可

**时间复杂度：** 
外层循环执行$O(m)$次，每次循环`j`最多加`1`,`j`最多加了$M-1$次，而`j`的回退不会超过$M-1$

外层循环执行了$O(M-1)$次
内层`while`循环条件判断和回退操作，摊分到整个执行过程，最多执行了$O(M-1)$次
总的时间复杂度：$O(M-1)+O(M-1)=O(M-1)$


```C++
class Solution {
public:
    int strStr(string haystack, string needle) {
        int n = haystack.size(), m = needle.size();
        vector<int> next(m, 0);
        for (int i = 1; i < m; i++) {
            int j = next[i - 1];
            while (j > 0 && needle[i] != needle[j]) {
                j = next[j - 1];
            }
            if (needle[i] == needle[j]) {
                j++;
            }
            next[i] = j;
        }
        int i = 0, j = 0;
        while (i < n && j < m) {
            if (haystack[i] == needle[j]) { //顺利匹配
                i++, j++;
            } else if (j == 0) { //模式串第一个都匹配不 上，退无可退，只能主串前进，不然陷入无限循环
                i++;
            } else { //主串不动，子串最大步跳跃
                j = next[j - 1];
            }
        }
        if (j == m)
            return i - m;
        else
            return -1;
    }
};
```
