PPT 风格预览

个人作品集网站分享 — 面向社团/同学的 8-12 页标准版 PPT。下方提供 3 种风格方向，每种含首页/目录页/正文页预览。

使用方式
先展开候选方案，再点击图片放大查看细节。
注意
当前环境无 AI 图像生成能力，预览图为 SVG 示意，仅供风格方向比较。
选定风格后可用外部工具生成高清预览。
💡 请选择一个最合眼缘的风格方向，确认后我将基于该风格完成整份 PPT 的内容规划与生成。
首页：看气质 目录页：看结构 正文页：看可用性 卡片：看提案理由
A 推荐

方案 A ｜ 霓虹科技风

延续个人网站的深色主题 + 三色渐变体系，粒子网络元素贯穿全篇，科技感十足，适合技术分享场景。

一句话定位
深色科技 + 渐变霓虹，和你的网站视觉高度一致，社团技术分享首选。
封面页方向
深色底色上，粒子连线网络作为背景纹理，中央大号渐变标题「个人作品集」，右侧放置网站缩略图剪影。
正文页视觉语法
深色卡片容器 + 渐变边框高亮，技能条/项目卡片用三色渐变进度条，信息密度适中，重点用发光色块标注。
配色
底色 #0a0a1a · 主色 #6c63ff · 辅色 #00d4aa · 点缀 #ff6b9d
风险点
投影环境不佳时深色背景对比度不足，需确保会场屏幕亮度够。
首页
深色底色 + 粒子网络 + 渐变标题，一眼看出是技术向个人展示。
目录页
编号卡片 + 渐变分隔，结构清晰，适合展示章节层次。
正文页
技能卡片网格 + 渐变进度条，信息密度适中，一眼看懂能力分布。
B 清爽路线

方案 B ｜ 极简留白风

纯白底色 + 大面积留白 + 少量彩色点缀，干净清爽，适合社团展示，投影效果好。

一句话定位
白底留白 + 少量彩色强调，干净清爽，投影友好，适合非正式分享。
封面页方向
大面积白色留白，左侧放置一个彩色圆形色块（取网站三色之一），右侧大号黑色标题 + 灰色副标题，极简但有记忆点。
正文页视觉语法
白色卡片容器 + 细灰边框，关键数字/百分比用三色渐变圆角矩形标注，留白充足，阅读无压力。
配色
底色 #ffffff · 文字 #1a1a2e · 点缀 #6c63ff / #00d4aa / #ff6b9d（各占 10%）
风险点
过于简约可能缺乏视觉冲击力，需要靠内容质量和排版节奏取胜。
首页
大面积留白 + 彩色圆点装饰，极简但有记忆点。
目录页
白色卡片 + 细线分隔，阅读无压力，投影效果优秀。
正文页
白色卡片列表 + 彩色百分比标签，清晰易读。
C 现代质感

方案 C ｜ 暗色磨砂风

深灰底色 + 毛玻璃卡片 + 柔和渐变光晕，现代感强，兼顾专业与轻松氛围。

一句话定位
深灰 + 毛玻璃 + 渐变光晕，现代感强，专业但不严肃。
封面页方向
深灰底色上叠加柔和的紫色/青色渐变光晕，中央毛玻璃卡片内放置标题，卡片半透明模糊效果增加层次感。
正文页视觉语法
毛玻璃卡片作为信息容器，卡片间用间距而非边框区分，渐变光晕作为装饰元素穿插，信息层级通过字号和卡片大小体现。
配色
底色 #1a1a2e · 卡片 rgba(255,255,255,0.06) · 光晕 #6c63ff / #00d4aa（低透明度）
风险点
毛玻璃效果在投影上可能不明显，部分细节会丢失。
首页
深灰底色 + 渐变光晕 + 毛玻璃卡片，现代质感拉满。
目录页
毛玻璃卡片列表 + 左侧渐变竖条，层次分明。
正文页
毛玻璃卡片排列 + 渐变进度条，现代感与信息量平衡。
